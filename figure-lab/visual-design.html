第六章阅读与图表视觉方案

日期：2026-10-10。范围：独立试读页；沿用已有题目、模型和经典教材图示依据。

界面精修：更早进入正文，阅读中便于对照

上一版把章节下拉、版本说明、知识点目录、来源文字、图解目录和重复图解入口分散排列。375px窗口的首个知识点约在673px处。本轮合并入口与留白后约在445px处，正文宽度和字号保持原设定。1280px从665px提前至472px。比较基线为4912d62，截图及几何读数见 qa-interface/first-screen-comparison.json。

  • 章节信息与选择器在宽屏同排，手机保持自然的上下顺序；侧栏选中态使用已有操作蓝。
  • 版本切换采用文字、下划线和字重共同标识，阅读时固定在纸张顶部；标题跳转预留80px，避免被遮挡。
  • 知识点、图解和阅读说明集中在一行。次要说明仍可读取，数学前提和计算表继续放在正文与图旁。目录可用键盘操作，Escape关闭后焦点回到入口；当前知识点明确标出。
  • 图表保留完整宽度，去掉控制区整块灰底和分项结果的重复框；用间距、细分隔及数值字重组织层次。曲线、计算过程和选中行承担注意力。

作者查看了1280/1920px浅色、375px深色、保护性看跌相加的暂停帧。320px检查发现版本文字换行使页首过高，减少分栏间距后保持一行。自动验证包含目录互斥开合、Escape焦点、点外关闭、图解跳转、三版对应和固定栏不遮挡标题；既有正文、图表及动画回归通过。没有独立设计审阅或实体设备测试。

学习的来源与实际采用

  • Anthropic frontend-design / SKILL.md：本次在线阅读全文，作为设计工作法使用；未声称全局安装。先定主题、字号、配色和构图，实施后看截图再修正。装饰、编号和色块必须有用途。
  • Primer Layout：自然阅读顺序、安静聚焦、移动端保持功能；不照搬桌面多栏。
  • Primer Typography：明确标题、正文、辅助文字的角色和字号，不用同一字号承担全部层次。
  • Primer Button：区分主要操作与次要操作，保持键盘焦点可见。
  • Primer Data visualization：明确轴与单位、直接标注曲线、线型辅助区分、选中价格与表格对应。
  • Primer Progressive disclosure：仅将次要参考信息折叠，展开不打断当前阅读位置。

这些规范提供设计依据，不自动证明审美达标。本轮是作者截图复核与功能验证，不能称为独立设计审核或读者试读。

本项目的视觉方向

对象是读 CPA 教材的人。最重要的视觉内容是“价格变化后，哪一笔现金流怎样改变”。保留宽正文和分知识点阅读，每幅图始终围绕一个问题。界面采用克制的 GitHub 式文字、边界和控件层次；不加封面大数字、渐变、装饰插画或无关进场动画。

浅色基础沿用项目变量：纸白 #ffffff、浅灰 #f5f5f7、主文字 #1d1d1f、次文字 #6e6e73、操作蓝 #0066cc、结论绿 #1f7a37。图形语义仍遵守共享规范：净收入靛色实线、净损益橙色虚线、合计绿色；深色使用同名主题变量，不修改共享 tokens。

字体沿用系统无衬线中文字体；数学保留数学字体。正文 20px / 2，知识点标题 24px / 1.55，图标题 20px / 1.6，图内计算 15px，控件与辅助说明 12–14px。数字用等宽数字特性，不另换装饰字体。正文最大 1120px，用户仍可选 720px 标准宽度。

间距以 4/8/12/16/24/32/48px 为骨架：相关对象靠近，知识点之间明显分开，边框只标识可操作图解、题目与表格的边界。

构图与自我批评

旧布局：图与公式并排，右侧仅 250px；播放远在表格之后。公式断裂，读者来回找计算和控件。

不采用另一种常见的卡片墙布局：本章要连续推理，不能把每个自然段拆成等权卡片。正文保持开放排版；题目与解析连在同一块，普通强调与最终要点使用不同层次。删除图头重复标签，弱化辅助编号，图形和数字承担主要注意力。图表数值、模型前提和完整计算表不以美化为由删除。

发布前检查

先看实际“看涨空头、保护性看跌、BS长公式、自查题”桌面截图，检查焦点、主次、对齐与空白；再检查移动端和深色。随后覆盖三版本、八单元、42幅图的溢出与交互回归。自动验证只能检查功能、边界和内容保存；视觉判断必须另看截图。
